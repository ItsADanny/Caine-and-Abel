# Caine &amp; Abel - Process &amp; Machine manager
A simple process &amp; machine management tool, that can display multiple machines and what the running process are

This tool is divided into 2 parts, the controller "Caine" and the nodes "Abel"
---

Caine, needs to only be installed on a machine and is meant to be the main controller for the manager. Caine can also perform the same tasks as abel but only on the machine its installed on.
Abel is a node, which can be installed on machines that need to be controlled through Caine. Abel will report all process to Caine from which any wished for data analytics can be run. This data can be exported to CSV, JSON or to a MySQL, Postgress or SQLite Database if needed.
